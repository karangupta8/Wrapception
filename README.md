## Problem
Every year, dozens of apps generate beautiful but siloed “Year in Review” summaries. These insights are fragmented across platforms, locked inside screenshots, stories, and PDFs, making it impossible to compare, correlate, or reflect on holistically.

> You don’t live your life in apps. Your data does.

## Solution
**Wrapception** is a web app that lets users upload Year‑End summaries (images, PDFs, text) from all their services and uses AI to generate a single, intelligent, cross‑domain annual view of their life.

- One unified dashboard
- One coherent narrative
- One memory they actually own

---

## How It Works (Simple & Powerful)

1. **Upload** – Add your year-end summaries via drag-drop, file upload, or paste text
   - Supports: Screenshots (PNG/JPG), PDFs, plain text
   - Automatic platform detection (Spotify, Strava, GitHub, etc.)
   
2. **Configuration** – Choose your AI provider (OpenAI, Claude, Gemini, etc.) and API key
   - See cost estimates before processing ($0.01–$0.10 per run)
   - All processing happens in your browser (no server uploads)
   
3. **AI Extraction** – Intelligent per-source extraction pipeline
   - Platform-aware prompts (Spotify template extracts different metrics than Strava)
   - Multimodal support: vision APIs handle screenshots, text extraction for PDFs
   - Per-source failure isolation: one source failure doesn't stop the pipeline
   
4. **Validation & Review** – Inspect confidence scores and extracted metrics
   - See which platform the AI detected (with confidence %)
   - Review and edit metrics if needed
   - Retry failed extractions
   
5. **Intelligent Dashboard** – AI-generated insights with dynamic charts
   - Auto-selected chart types (Pie/Bar/Line/Radar based on data)
   - Year-in-review narrative generated by AI
   - Cross-platform patterns and trends

## Getting Started

### Quick Start (No API Key Required)
1. Open the app and click **"Try Demo"** to explore with sample data
2. See how extraction works, view charts, and understand the UX
3. No API key or configuration needed

### Full Setup (With Your Data)
```sh
# Clone the repository
git clone <YOUR_GIT_URL>
cd wrapception

# Install dependencies
npm install

# Start dev server (http://localhost:8080)
npm run dev

# Build for production
npm run build
```

### Configuration
1. Navigate to the app
2. Go to **Settings** (gear icon) → **AI Configuration**
3. Select provider (OpenAI, Claude, Gemini, etc.)
4. Paste your API key
5. Choose your preferred model

**Note**: Your API key is encrypted (optional passphrase available) and never leaves your browser.
